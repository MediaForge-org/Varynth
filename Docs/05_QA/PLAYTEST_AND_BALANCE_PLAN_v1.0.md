# PLAYTEST & BALANCE PLAN v1.0 — PASS 10

## 1. Balancing wird nicht theoretisch finalisiert

Die Balancing Bible liefert Startwerte. Releasewerte entstehen aus reproduzierbaren Testständen.

## 2. Phasen

### A — Systemtest
Ein System isoliert: Produktion, Lager, Straßen, Bedürfnisse, Forschung.

### B — Vertical Slice
Occidentia frühes/mittleres Spiel + Händler/Piraten + erste Storyquests.

### C — Regionstests
Jede Region einzeln bis zur höchsten vorgesehenen Grundspielstufe.

### D — World Economy
Mehrere bekannte Regionen, Handel, Expeditionen, KI.

### E — Ultima
U0–U5, Cross-Region, Äther, Fraktionen, Endgame.

### F — Full Campaign
80–140h-Zielband prüfen, ohne künstliche Wartezeiten.

## 3. Metriken

- Zeit bis Freischaltung;
- Produktionssaldo;
- Lagerreserve;
- Arbeitskräfte;
- Geldsaldo;
- Transport-/Rampenauslastung;
- Forschungstempo;
- Questdauer;
- Abbruch-/Fail-Safe-Fälle;
- KI-Expansion;
- Piratendruck;
- Anzahl erzwungener Imports;
- FPS/Memory/Savegröße.

## 4. Balanceänderungen

Jede Änderung braucht:
- vorheriger Wert;
- neuer Wert;
- Grund;
- Testsave;
- erwarteter Effekt;
- tatsächlicher Effekt.

Keine stillen „gefühlt besser“-Änderungen an hunderten Werten.
