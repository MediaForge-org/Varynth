1. Template: **Universal 3D / URP**.
2. `Edit > Project Settings > Version Control`:
   - Mode: **Visible Meta Files**.
3. `Edit > Project Settings > Editor`:
   - Asset Serialization: **Force Text**.
4. Projekt-/Companyname vorerst als Codename verwenden; Produktname später ändern.
5. Noch keine zufälligen Asset-Store-Pakete installieren.
6. Packageänderungen nur dokumentiert/committed.
7. Addressables erst im vorgesehenen Engineering-Paket aktiv konfigurieren.
8. Desktopziele: Windows, Linux, macOS architektonisch berücksichtigen.
9. Fehlender lokaler Windows Build Support auf Fedora blockiert Phase 0 nicht.
10. Unity-Patchversion nach erstem erfolgreichen Öffnen in `Docs/00_START_HERE/DECISIONS.md` eintragen.
